Motherboard AR — Interactive Learning System

An Augmented Reality (AR) based interactive learning platform designed for engineering students to explore motherboard architecture through immersive visualization and guided interaction.

This system allows students to identify motherboard components, understand their functionality, and practice assembly virtually using standard mobile devices.
